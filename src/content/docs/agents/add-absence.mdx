import {Steps} from "@astrojs/starlight/components";

<Steps>

1. Navigate to the absences section of the dashboard and click on _Add Absence_

   ![Empty absence list](./assets/add-absence/1-empty-absences-list.png)

1. A modal with a form opens.
   - Select the absent **type** one-time or recurring
   - Select the absent **agent**
   - Change the **reason**, if you want to track it here.
   - Select a range for the absence. The **to date** must be in the future.

   ![Add absence form](./assets/add-absence/2-add-absence-form.png)

   If you've selected a recurring absence, additional options for the recurrence pattern will appear:
   - Select the **weekday/s**
   - Select the **from** and **to** times

   :::tip
   To set this for a long period select a **To Date** far in the future.
   :::

   ![Add absence form](./assets/add-absence/2-add-absence-form-recurring.png)

1. Click _Add Absence_ and it will be saved.
   ![Add absence form saved](./assets/add-absence/3-absence-added.png)

   Recurring absences will have a circular icon indicating their recurrence.

   ![Add absence form saved](./assets/add-absence/3-absence-added-recurring.png)

</Steps>
