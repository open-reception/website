## Automation and End-to-End Encryption

All automation features in OpenReception are designed with end-to-end encryption in mind. This ensures that your data remains secure and private.

Due to End-to-End Encryption, the server cannot decrypt anything. This means all automations must be executed on the client side. You will need to be logged-in for automations to run.

:::note
We know this is an issue and are actively working on solutions.
:::
